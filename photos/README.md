# Destination photos

Put one photo per destination in this folder, named exactly as below (JPG).
The site shows the photo in the side panel and at the top of the destination page.
If a file is missing, the site shows its placeholder illustration instead.

```
umm-qais.jpg  <-  أم قيس (Umm Qais)
jerash.jpg  <-  جرش (Jerash)
ajloun.jpg  <-  قلعة عجلون (Ajloun Castle)
pella.jpg  <-  طبقة فحل (Pella (Tabaqat Fahl))
himma.jpg  <-  الحمة الأردنية (Al-Himma Hot Springs)
yarmouk.jpg  <-  محمية غابات اليرموك (Yarmouk Forest Reserve)
citadel.jpg  <-  جبل القلعة (Amman Citadel)
theatre.jpg  <-  المدرج الروماني (Roman Theatre, Amman)
madaba.jpg  <-  مادبا (Madaba)
nebo.jpg  <-  جبل نيبو (Mount Nebo)
dead-sea.jpg  <-  البحر الميت (The Dead Sea)
iraq-al-amir.jpg  <-  عراق الأمير (Iraq al-Amir)
mujib.jpg  <-  وادي الموجب (Wadi Mujib)
machaerus.jpg  <-  قلعة مكاور (Machaerus (Mukawir))
petra.jpg  <-  البتراء (Petra)
little-petra.jpg  <-  البتراء الصغيرة (Little Petra (Siq al-Barid))
wadi-rum.jpg  <-  وادي رم (Wadi Rum)
aqaba.jpg  <-  العقبة (Aqaba)
dana.jpg  <-  محمية ضانا (Dana Biosphere Reserve)
shobak.jpg  <-  قلعة الشوبك (Shobak Castle)
karak.jpg  <-  قلعة الكرك (Karak Castle)
ben-hammad.jpg  <-  وادي بن حماد (Wadi Ben Hammad)
feynan.jpg  <-  فينان (Wadi Feynan)
jabal-haroun.jpg  <-  جبل هارون (Jabal Haroun)
```

Tip: use landscape photos around 1600 px wide, and only photos you own or have the right to use (credit the photographer if the license requires it).
